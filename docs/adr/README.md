# Architecture Decision Records

One file per decision, numbered `NNNN-short-title.md`, newest last. Keep each record to the
decision, the options that were weighed, and the consequence that is now binding.

Write one when a choice would otherwise be re-litigated: a protocol boundary, a threading or
ownership model, a dependency policy, a storage or lifecycle rule.

Any output that contradicts a record must say so explicitly rather than quietly overriding it.
